1. Class dan Object

Class merupakan blueprint atau cetakan untuk membuat object. Object adalah hasil instansiasi dari class. 


class Car {
 String? model;
 String? color;

 void start(){
  print("Car started");
 }

 void stop(){
  print("Car stopped");
 }
}

2. Constructor

Constructor adalah method khusus yang dipanggil saat object dibuat. 


class Car{

 String model;
 String color;

 Car(this.model,this.color);

 void start(){
  print("Car started");
 }

}
