Pengertian OOP (Object Oriented Programming)

Object Oriented Programming (OOP) adalah paradigma atau metode pemrograman yang menggunakan konsep objek untuk mengatur dan membangun program. Dalam OOP, program dibuat dengan mengelompokkan data dan fungsi ke dalam suatu class dan object, sehingga kode menjadi lebih terstruktur, mudah dipahami, dan mudah dikembangkan. Konsep ini juga membantu programmer mengelola program yang besar dengan membagi program menjadi bagian-bagian yang saling berhubungan.

Konsep dasar

    → Class: Blueprint atau cetakan untuk membuat objek.
  • → Object: Instance nyata yang tercipta dari sebuah class.
  • → Attribute: Representasikan data melalui variabel di dalam class.
  • → Method: Logika fungsional atau fungsi di dalam class.

1. Class Sederhana

Class adalah blueprint untuk membuat objek. Class Car memiliki atribut model dan color serta method start() dan stop(). Contohnya : 


// Nama   : M. Bagas Khoirullah
// Nim    : 251410016
// Kelas  : SI2A
  
  class Car {
  String? model;
  String? color;

  void start() {
    print('Car started!');
  }

  void stop() {
    print('Car stopped!');
  }
}

2. Object Instantiantion

Object instantiation adalah Proses menciptakan objek konkret dari class Car yang telah didefinisikan sebelumnya menggunakan fungsi main(). 


// Nama   : M. Bagas Khoirullah
// Nim    : 251410016
// Kelas  : SI2A
  
void main() {
  Car myCar = Car();

  myCar.model = "Sedan";
  myCar.color = "Merah";

  print(myCar.model);
  print(myCar.color);
}

3. Constructor

Constructor adalah metode khusus dalam pemrograman yang secara otomatis dipanggil ketika sebuah object dibuat dari class. Constructor memudahkan kita mengisi nilai atribut langsung saat objek diciptakan (inisialisasi). 


// Nama   : M. Bagas Khoirullah
// Nim    : 251410016
// Kelas  : SI2A
  
  class Car {
  String model;
  String color;
  Car(this.model, this.color);
  
  void start() {
    print('Engine Online: $model');
  }

5. Encapsulation

Encapsulation adalah Teknik keamanan data dengan menyembunyikan akses langsung ke variabel internal menggunakan prefix underscore. Contohnya : 


// Nama   : M. Bagas Khoirullah
// Nim    : 251410016
// Kelas  : SI2A
  
  class Person {
  String _name;
  int age;
  Person(this._name, this.age);
  void setName(String name) {
    _name = name;
  }

  String getName() {
    return _name;
  }
}

6. This keyword

Sebagai rujukan eksplisit ke instance class saat ini untuk menghindari kebingungan nama antara field dan parameter.

7. Named Parameter Constructor

Penggunaan Named Parameters dan Required untuk menciptakan objek yang lebih deskriptif dan aman. Contohnya : 


// Nama   : M. Bagas Khoirullah
// Nim    : 251410016
// Kelas  : SI2A
  
  class Produk {
  final String id;
  final String nama;
  final double harga;

  Produk({
    required this.id,
    required this.nama,
    required this.harga,
  });
}

Kesimpulan

Object Oriented Programming(OOP) adalah metode pemrograman yang menyusun program dengan menggunakan konsep class dan object sehingga kode menjadi lebih terstruktur, mudah dipahami, dan mudah dikembangkan. OOP memungkinkan penggabungan data dan fungsi dalam satu kesatuan serta memberikan perlindungan terhadap data melalui berbagai konsep seperti encapsulation, constructor, dan object instantiation. Dengan menggunakan OOP, pengembangan program dapat dilakukan dengan lebih efisien, terorganisir, dan memudahkan proses pemeliharaan serta pengembangan sistem di masa depan.
