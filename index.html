Pengertian OOP (Object Oriented Programming)

Object Oriented Programming (OOP) adalah paradigma atau metode pemrograman yang menggunakan konsep objek untuk mengatur dan membangun program. Dalam OOP, program dibuat dengan mengelompokkan data dan fungsi ke dalam suatu class dan object, sehingga kode menjadi lebih terstruktur, mudah dipahami, dan mudah dikembangkan. Konsep ini juga membantu programmer mengelola program yang besar dengan membagi program menjadi bagian-bagian yang saling berhubungan.

1. Class dan Object

Class adalah rancangan atau blueprint dalam pemrograman berorientasi objek yang digunakan untuk mendefinisikan atribut (data) dan metode (fungsi). Sementara itu, object adalah hasil atau instansi yang dibuat dari sebuah class sehingga dapat digunakan dalam program. Dengan kata lain, class merupakan cetakan, sedangkan object adalah wujud nyata yang dibuat dari cetakan tersebut. Contohnya : 


class Car {
  String? model;
  String? color;

  void start() {
    print('Car started!');
  }

  void stop() {
    print('Car stopped!');
  }
}

2. Object Instantiantion

Object instantiation adalah proses membuat sebuah object dari suatu class dalam pemrograman berorientasi objek (OOP). Pada proses ini, class yang berfungsi sebagai blueprint digunakan untuk menghasilkan object yang dapat digunakan dalam program dan memiliki atribut serta metode yang telah didefinisikan dalam class tersebut. 


class Car {
  String? model;
  String? color;
}

void main() {
  Car myCar = Car();

  myCar.model = "Sedan";
  myCar.color = "Merah";

  print(myCar.model);
  print(myCar.color);
}

3. Constructor

Constructor adalah metode khusus dalam pemrograman berorientasi objek (OOP) yang secara otomatis dipanggil ketika sebuah object dibuat dari class. Constructor digunakan untuk menginisialisasi atau memberikan nilai awal pada atribut yang dimiliki oleh object tersebut agar object dapat langsung digunakan sesuai dengan kebutuhan program. Contohnya : 


class Car {
  String model;
  String color;
  Car(this.model, this.color);
  
  void start() {
    print('Engine Online: $model');
  }
}
void main() {
  Car myCar = Car("Sedan", "Merah");
  myCar.start();
  print(myCar.color);
}

4. Validasi Data

Validasi adalah proses pemeriksaan terhadap data atau input untuk memastikan bahwa data tersebut benar, sesuai aturan, dan layak digunakan sebelum diproses lebih lanjut dalam sebuah program atau sistem. Tujuan validasi adalah untuk mencegah kesalahan, menjaga keakuratan data, dan memastikan data yang masuk sesuai dengan ketentuan yang telah ditetapkan. Contohnya : 


class Mahasiswa {
  String nama;
  String nim;
  double ipk;
  
  Mahasiswa(this.nama, this.nim, this.ipk) {
    // Validasi sederhana untuk IPK (rentang 0.0 - 4.0)
    if (ipk < 0.0 || ipk > 4.0) {
      throw ArgumentError('IPK harus berada dalam rentang 0.0 - 4.0');
    }
  }
  void tampilkanData() {
    print('===== Data Mahasiswa =====');
    print('Nama : $nama');
    print('NIM  : $nim');
    print('IPK  : $ipk');
    print('==========================');
  }
  String toString() => 'Mahasiswa(nama: $nama, nim: $nim, ipk: $ipk)';
}

5. Encapsulation

Encapsulation adalah konsep dalam pemrograman berorientasi objek (OOP) yang digunakan untuk membungkus data (atribut) dan metode (fungsi) ke dalam satu kesatuan yaitu class, serta membatasi akses langsung terhadap data tersebut. Tujuannya adalah untuk melindungi data agar tidak dapat diubah secara sembarangan dan hanya dapat diakses melalui metode tertentu yang telah ditentukan. Contohnya : 


class Person {
  String _name;
  int age;
  Person(this._name, this.age);
  void setName(String name) {
    _name = name;
  }

  String getName() {
    return _name;
  }
}

7. Named Parameter Constructor

Named parameter adalah parameter dalam sebuah fungsi atau method yang dipanggil dengan menyebutkan nama parameternya secara langsung saat memberikan nilai. Cara ini membuat kode lebih jelas, mudah dibaca, dan tidak bergantung pada urutan parameter, karena setiap nilai sudah ditentukan berdasarkan nama parameternya. Contohnya : 


class Produk {
  final String id;
  final String nama;
  final double harga;

  Produk({
    required this.id,
    required this.nama,
    required this.harga,
  });
}
